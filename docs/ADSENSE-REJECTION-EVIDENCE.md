## Triage mapping after the exact reason is supplied

| Account wording | Evidence to inspect | Planned stage |
| --- | --- | --- |
| Low value / little or no original content | Tool-specific methods, examples, acceptance criteria, editorial depth, repeated copy | Stage 2 |
| Navigation / user experience | Tool input UX, mobile layouts, Agent, Workstation, Community, Updates | Stages 2–3 |
| Policy / privacy / consent | Privacy disclosures, CMP configuration, ad separation, prohibited content | Stage 4 plus account configuration |
| Site unavailable / code missing | Live reachability, HTTPS, Auto Ads tag, ads.txt, deployment history | Stages 1 and 4 |
| Unsupported language / localization | Language routing, hreflang, localized content and UI | Stages 1–4 |

An audit pass is evidence of implementation quality, not a guarantee of acceptance. Google retains the final review decision.
